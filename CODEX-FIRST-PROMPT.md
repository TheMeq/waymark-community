# First Prompt for Codex

Use this after extracting this repository and opening the folder in Codex:

> This repository is the approved design and implementation baseline for **Waymark Community** (internal project name **Waymark**). Begin by reading `START-HERE-FOR-CODEX.md`, then `AGENTS.md`, the full design specification, the master roadmap, the approved homepage concept image, and the Phase 1 foundation plan. Implement **Phase 1 only**, task-by-task, using TDD and small commits. Do not jump ahead into product modules. Do not alter approved product scope or visual direction. Stop at the Phase 1 acceptance gate, run every required verification command, summarise the evidence, and ask for review before beginning Phase 2.

The mandatory visual-fidelity gate occurs in Phase 2. The public site must materially follow `docs/design/references/approved-homepage-concept.png`; a generic Laravel/Filament/Bootstrap-style public frontend is not acceptable.
