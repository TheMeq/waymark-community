# Waymark Community — Product Summary

**Waymark Community** is a generic self-hosted platform for one walking group per installation. It combines a modern public community website with volunteer-friendly administration for walks, socials, holidays, galleries, content, governance documents, committee information, and safe site operations.

NDWG is the reference installation. The platform itself must contain no NDWG-specific assumptions.

## v1 personality

Public side: modern, photographic, social, concise, welcoming.  
Admin side: restrained, clear, volunteer-friendly, safe.  
Operations: shared-host compatible, recoverable, portable, reproducible.

See the full specification under `docs/superpowers/specs/`.

## Naming

External product name: **Waymark Community**. Internal project name: **Waymark**.
