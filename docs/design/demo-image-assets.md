# Phase 2 Demo Image Assets

The four images in `public/images/demo/` are deterministic, repository-owned
fixtures for the Phase 2 visual foundation. They are not installation content,
runtime uploads, or substitutes for the later moderated media workflow.

They were created with OpenAI's built-in image-generation tool on 20 August
2026 using the `photorealistic-natural` use case. All prompts required natural
editorial walking photography, unbranded clothing, believable British
landscapes, no text, no logos and no watermarks.

| File | Prompt subject and composition |
| --- | --- |
| `hero-walkers.png` | Five adult friends on an upland trail, subjects on the right with clear landscape space on the left for hero copy. |
| `woodland-walk.png` | Three walkers crossing a wooden footbridge through fern-rich woodland, framed for event cards. |
| `coastal-weekend.png` | Walkers arriving at a stone lodge on a broad coastal headland in restrained late-afternoon light. |
| `lakeside-friends.png` | A candid group sharing a flask beside an upland lake, framed for compact gallery crops. |

The approved concept artwork remains unchanged at
`docs/design/references/approved-homepage-concept.png` and is not reused as a
runtime image.
